# 创建「天气材质渲染」skill

请在天光天气壁纸 Agent 项目中使用 $skill-creator，创建可独立运行的 `skills/weather-material-renderer`。触发场景是用户已有照片、分区和天气物理交接，希望把表面变化做成可叠加的视觉图层。请交付可执行实现、中文 SKILL.md 和实际运行的样例。主 Agent 负责用户问答和桌面打包，这个 skill 读取已确认的答案。独立开发时将代码放在自己的技能目录，以便之后接入主入口。

## 读取什么

先读项目的 `skills/scene-regions/SKILL.md`、`skills/weather-surface-physics/SKILL.md`、`skill_pipeline.py`。输入是原图、分区 manifest.json、物理 handoff.json、天气方案与要生成的天气。详细仿真的通道约定见物理 skill 的 `references/renderer.md`。识别普通位置交接和详细仿真的不同格式，按实际提供的字段运行。

核对原图文件指纹、分区清单指纹、EXIF 校正后的像素坐标与尺寸。位置蒙版是离散状态：255 允许绘制该现象，0 和 127 对应的该现象图层必须全透明。先生成连续纹理，再在最终输出尺寸裁剪，保护细枝边界、车窗轮廓和题字。不同现象分别判断，例如允许湿润的路面仍可能完全没有水洼。

## 怎么画

- 小雪用稀疏的局部薄雪，显出底色；中雪让可承雪面出现连片斑块；大雪与暴雪逐步改变覆盖率、厚薄感和边缘形状。同一档的积雪固定。高速主体沿用已确认的留存条件，详细仿真已经计入的运动或遮挡系数只应用一次。
- 同一场雪在不同材质上要看得出差异。沥青保留粗糙纹理和透视，草叶积雪随叶簇分布，树枝沿承雪一侧附着；车漆上的薄雪应透出原色并保留车身曲面。纹理尺度随远近变化，阴影和高光方向取自原照片。
- 小雨和大雨分别控制湿色、水膜与局部反射。普通湿润使用有依据的湿润或接触通道；积水反射受积水许可蒙版约束。输入只有积水位置时，只交付能得到支持的效果。
- 霜表现为细颗粒哑光，露表现为离散水珠，冻雨挂冰沿获准的受雨面附着，再冻结按先前有水的区域呈薄冰，冰雹按可截留位置绘制颗粒堆积。上游缺少某现象、只给文字结论或全部像素均未获准时，在清单里写明原因并交付相应空效果。禁止从反光臆造水源或冰面。

## 交付和验收

提供本地命令，输入文件路径和天气即可复现。输出按天气与现象命名的透明 RGBA 图层、原图叠加预览和 `materials.json`。清单写明版本、原图与分区指纹、方向、尺寸、天气档、图层顺序、合成方式、相对路径和随机种子，让动画和验收 skill 都能直接读取。

用一张含赛车与路面的照片验证留雪随材质和动静变化，再用一张含水面、植被或其他主体的照片验证泛化。逐像素检查禁止区与保守略过区的积留层 alpha 均为零。提供同一局部的小雪／大雪对照，以及一个「路面湿润但没有水洼」的例子。相同输入和种子应能复现同一结果。交付时给出实际命令、文件和发现的边界误差。
