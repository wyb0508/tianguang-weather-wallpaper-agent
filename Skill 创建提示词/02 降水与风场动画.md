# 创建「降水与风场动画」skill

请在天光天气壁纸 Agent 项目中使用 $skill-creator，创建 `skills/weather-particle-motion`。用户要求让雨雪有前后景、随风运动、在获准的落点产生飞溅或涟漪时触发。输出要能在本地 HTML 和 macOS WKWebView 运行。交付可执行实现、中文 SKILL.md 和离线演示。将实现放在自己的技能目录，沿用主 Agent 已确认的主体与动静状态。

## 输入与坐标

先看项目的 `templates/scene.js`、`templates/scene.html` 和物理 skill 的 `references/renderer.md`。读取原图、分区清单、天气方案，以及实际可用的相对深度和物理通道。若已提供 `materials.json`，按其图层顺序叠加；材质 skill 尚未完成时，原图也应能独立演示动画。

验证图像指纹与方向。让照片、蒙版、粒子和落点共用一套坐标映射，在横屏、竖屏、缩放和居中裁切时保持对齐。相对逆深度远黑近白，先统一粒子和场景的深度尺度再比较。只有分组蒙版时，降级为明确的前后两层遮挡，并在输出中标明精度。

## 动画规则

- 为小雪、中雪、大雪、暴雪分别设计密度、远近分布和可见度。远景颗粒较细，近景允许少量清晰雪花。强降雪可以更密，横向偏移由风向和风速决定。雪花循环后，已确认的固定积雪层应保持原状。
- 小雨表现为稀疏细雨，大雨增加雨线密度、速度感和获准落点的响应。横风改变雨线方向；大风无降水时仍可表现风势。晴朗或纯光照预设应能清空上一档的雨雪。
- 用帧间经过时间推进粒子。后方粒子经过赛车轮廓时应被车身挡住；前方粒子可以掠过车头。赛车高速运动不等于相机移动，也不代表整幅背景都在逆向刮风。
- 有接触或轨迹相交依据才生成碰撞。现有水面收到直接雨滴可形成涟漪；局部积水另读对应许可。详细仿真提供配对的滴水出口、落点时才生成对应滴水。缺少证据时保留空中降水。题字、信息栏在最终合成时保持清晰。
- 支持固定种子和指定时间采样，方便验收复现。页面隐藏时暂停，恢复时避免时间差造成粒子瞬移；尊重系统减少动态效果设置。沿用宿主的帧率预算，允许降低粒子数量或分辨率。

## 交付和验收

输出可嵌入的动画模块、可切换天气的本地预览及 `motion.json`。记录输入指纹、坐标映射、使用的深度或遮挡方式、天气参数、随机种子、时间单位、各图层插入位置和运行入口。暴露设置天气、调整视口、暂停、恢复、销毁的调用方式；重复切换后应只保留一个有效动画循环。

至少给出三组可重复验证的结果：同一位置的雪花在车前可见、车后被挡；水域边缘的涟漪在改变窗口比例后仍留在水内；大雨切回晴天后雨线和碰撞效果均消失。用指定种子和时间导出连续帧或短片，同时报告实际测到的帧间隔和测试环境。给出可离线运行的命令。
