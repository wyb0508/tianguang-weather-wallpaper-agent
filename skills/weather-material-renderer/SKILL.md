# 天气材质渲染

从照片和物理证据生成静态表面图层。使用主 Agent 确认并保存的天气方案，每次渲染一个天气档。输入包内的 PNG 与 JSON 保持原有相对位置。

```sh
"$SKILL_DIR/run.sh" "$PHOTO" --manifest "$REGIONS/manifest.json" \
  --handoff "$PHYSICS/handoff.json" --answers "$ANSWERS" \
  --weather 大雪 --seed 37 --out "$NEW_DIR"
```

`SKILL_DIR` 是本文件所在目录。启动器可复用项目 Python 环境。单独使用时，在技能目录用 Python 3.10–3.13 建立 `.venv`，用其中的 pip 安装 `requirements.txt`。命令全程无交互，输出到新目录。可用天气见 `run.sh --help`。

## 选择交接

- **位置交接**按具体天气或通用现象读取对应空间蒙版。只有值为 255 的像素可显色，其余状态在原尺寸将 alpha 清零。积雪量取固定雪档，按答案中的主体动静、地面留雪与遮挡处理。选择显著性主体且需要其轮廓时，使用带显著性主体区块的分区。
- **详细仿真**选择已模拟的同一天气及条件。取末帧的相对水当量，解码接触比例和局部材质，按原尺寸区块 ID 最近邻采样。同一场事件直接使用终态雪量，终态可包含尚未融化的旧雪。雨中存量雪单列为“已有积雪”。遮挡和运动已由仿真计算。
- 普通位置交接通常只交付积水位置。湿色需要湿润、接触、吸水或水膜证据，积水反射另取积水许可。可用 `--places "$PLACES/handoff.json"` 为详细仿真补充同一照片和分区的三值许可。再冻结使用上游已判定先前有水的专用位置。空通道、文字结论与缺失的空间证据在清单中留有原因。
- 图像绑定按上游协议分别核对原文件字节、正向像素、分区清单字节，以及方案中的可选分区签名。方向与坐标已转换为 EXIF 校正后的左上原点，输出保持原图尺寸。

## 交付

交付整个输出目录。下游读取 `materials.json`，在正向原图上按 `layers[].order` 升序叠加 `path` 指向的 PNG。采用直通 alpha、sRGB、source-over 混合。路径相对清单，`preview` 为合成后的 JPEG。空效果保留全透明图层及 `empty_reason`。晴朗等天气若没有存量雪，图层列表为空。

查看[双照片样例及验证](examples/验收.md)获取可直接运行的命令、同位置雪档对照和已观察到的边界误差。

允许渲染的已有浅水区域由位置交接的 standing_water 图定位，并与当前天气的积水许可求交集。
