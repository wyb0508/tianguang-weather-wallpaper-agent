# 两张照片的实际渲染与验收

样例包含原图、分区、物理交接、天气方案及五份实际渲染输出，可随技能目录一起复制。赛车使用项目的“赛车样图”和已核对的赛道分区。静止、高速是同一张图的两组对照条件。橡树使用静止树木作为主体。两组示例均采用自然地面、标准强度、种子 37。

## 复现命令

从项目根目录执行以下命令。输出写入本次新建的临时目录，随包输出在各样例的同名子目录内。

```sh
cd skills/weather-material-renderer
out=$(mktemp -d)
race=examples/race
oak=examples/oak

for item in '小雪 stationary light' '大雪 stationary heavy' '大雪 high_speed fast'; do
  read -r weather motion name <<END
$item
END
  ./run.sh "$race/photo.jpg" --manifest "$race/regions/manifest.json" \
    --handoff "$race/places/handoff.json" --answers "$race/$motion.json" \
    --weather "$weather" --seed 37 --out "$out/$name"
done

./run.sh "$race/photo.jpg" --manifest "$race/regions/manifest.json" \
  --handoff "$race/rain/handoff.json" --places "$race/places/handoff.json" \
  --answers "$race/high_speed.json" --weather 大雨 --seed 37 --out "$out/wet"

./run.sh "$oak/photo.jpg" --manifest "$oak/regions/manifest.json" \
  --handoff "$oak/places/handoff.json" --answers "$oak/stationary.json" \
  --weather 大雪 --seed 37 --out "$out/snow"
```

## 雪档、材质与运动

[小雪／大雪同一局部](同一局部-小雪与大雪.jpg)取赛车正向原图的左上角 (420, 370)、右下角 (1165, 785)，按原像素并排。雪量变化时使用同一纹理种子。小雪可见透底的局部薄雪，大雪时沥青出现连续斑块，车盖保留面板亮暗，草面沿叶簇留下深色间隙。

| 赛车静止时的天气档 | 积雪层 alpha 大于零的像素 | 全图平均 alpha（0–255） |
| --- | ---: | ---: |
| 小雪 | 124,436 | 3.661 |
| 中雪 | 322,488 | 15.986 |
| 大雪 | 647,703 | 54.993 |
| 暴雪 | 820,651 | 100.939 |

大雪下，车类像素平均 alpha 从静止时的 34.844 降到高速时的 1.182。只改动静状态后，车外的整个 alpha 数组逐像素相同；其中 road 类平均值为 99.425。单独将大雪的视觉强度从 standard 改成 strong，表面雪层逐像素相同。[静止赛车清单](race/heavy/materials.json) · [高速赛车清单](race/fast/materials.json)

橡树照片中，293,366 个像素有可见积雪。树冠枝杈与地表共用天气和种子，各自使用枝缘和地表纹理。上游给出的 863,148 个禁止像素和 420 个保守略过像素中，雪层非零 alpha 都为 0。[橡树预览](oak/snow/大雪-预览.jpg) · [橡树清单](oak/snow/materials.json)

## 路面湿润，没有水洼

赛车大雨采用按高速方案生成的 600 秒终态。road 类中 98,025 个像素出现湿色，89,120 个像素出现可见水膜。同一分区的积水许可在整张图的 1,573,352 个像素上均为 0，积水反射层全透明。预览中弯道外侧的橙色亮带也可在原照片中找到。[大雨预览](race/wet/大雨-预览.jpg) · [图层清单](race/wet/materials.json) · [积水反射 PNG](race/wet/大雨-积水反射.png)

## 边界误差与复核

- 赛车的初次自动交接把部分前风挡、车窗误判为承雪面。按原图核对轮廓后，通过物理技能的空间修订将前风挡及其上沿字带设为保守略过，近直立侧窗设为不留雪。重跑后，在赛车雪图的 692,770 个禁止像素、14,001 个保守略过像素中，所有雪档对照样例的非零 alpha 均为 0。[原尺寸修订坐标](race/review.json)
- 仍可观察到上游部位判断的残差。静止大雪样例中，检查前格栅矩形 (971, 580)–(1004, 640)，283 个像素获准，229 个产生雪点。前轮矩形 (704, 576)–(750, 632) 中分别为 276 和 264 个。这些近直立细部仍有可见误积。坐标均为左上闭、右下开。
- 橡树右侧细枝与浅色天空交界处，部分允许带宽于照片里的枝条。原尺寸裁剪能守住交接蒙版，无法从已误判为 255 的像素恢复真实枝缘。

## 重新验收

以下命令在技能目录内执行。项目中可用 `../../.venv/bin/python` 作为 `PYTHON`，独立环境可改为 `.venv/bin/python`。

```sh
PYTHON=../../.venv/bin/python
"$PYTHON" examples/verify.py
"$PYTHON" examples/check_protocol.py
```

第一项从命令行在临时目录重跑，对照五份样例的全部 PNG、JPEG 与 JSON 字节，检查四档雪的逐像素单调性、材质与动静差异，以及雪、霜、露、挂冰、再冻结和冰雹在 0、127 位置的 alpha。另覆盖同义天气名、文字交接、错图、错分区、错天气和错运动条件。随包结果使用 NumPy 2.3.5、Pillow 13.0.0、OpenCV 4.14.0；跨图像编码器版本的 JPEG 或 PNG 压缩字节可能不同。[实测数据](verification.json)

第二项使用带 EXIF 方向 6 的可控输入，核对超过 3200 像素的照片指纹、单像素细部、题字保护、末帧比例及未获准区域。保持终态相同并更换仿真记录和方案中的运动状态，可验证渲染器只使用已计入运动的终态量。另有仅积水许可、冰粒截留、雨中旧雪和无效状态值的检查。
