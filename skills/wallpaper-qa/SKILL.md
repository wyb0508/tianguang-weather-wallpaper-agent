# 壁纸视觉与性能验收

从实际交付的 HTML 和应用包取证。检测脚本只读作品，把报告写入另选的新目录。项目根目录下运行：

```sh
.venv/bin/python skills/wallpaper-qa/scripts/qa.py "作品/赛道天光·双技能" --out "/tmp/赛道验收-01"
```

Python 需要 Pillow 和 NumPy。浏览器探针使用 Node.js、Playwright 或 playwright-core，以及本机 Chrome/Chromium。可用 `NODE_PATH` 指定模块位置，`QA_CHROME` 指定可执行文件。macOS 应用探针需要 codesign、Swift 和 WebKit。缺依赖时继续独立检查，报告注明未测原因。退出码 0 表示通过，1 表示有失败，2 表示调用参数错误，3 表示证据不完整。

带 `release.json` 的作品默认走发布验收。直接运行上面的命令即可读取全部天气的交接，检查嵌入的材质和动画，并在 macOS 上通过应用自身的隔离测试入口试切天气。独立的表面坐标按原图指纹匹配。缺少抽查或原生采样时，保留预览并在报告中列入 `needs_review`。原生短测使用主屏尺寸，晴朗、大雨和暴雪各采三秒；风向与断开预报使用固定输入回放。长时间浏览器性能测量和版本比较可使用下方参数。

## 选择输入与核查依据

- 传入单个作品目录。默认查找「壁纸预览.html」以及唯一的 manifest、handoff、天气方案、materials 和 motion 清单。目录外的已知输入或同名多份时，使用 `--source`、`--manifest`、`--handoff`、`--plan`、`--materials`、`--motion`、`--entry` 指定。作品同时交付独立动画页面与主预览时，分别验收两个实际入口。核对源文件 SHA-256、方案的正向 RGB 像素指纹、分区包签名及交接字节摘要。只有有损预览时保留底图，原文件指纹与 EXIF 标未测。
- 逐像素核对 region → 原始 class、区域面积、组成员、二值蒙版与全图覆盖。对积雪、积水和湿润分别读取透明层与对应许可；0 与 127 单列，坐标在最终材质网格，原点左上。越界位图保留全部位置。详细仿真的连续通道按其时刻、尺寸和同区块映射解释，缺少三值依据时另记未测。空中粒子与湿色不参与积雪、积水的越界计数。
- 局部判断优先使用实拍原图。将车顶、车窗、树梢、草坪、题字边缘的坐标写成 `{"车顶":[x,y]}` 形式的 JSON，通过 `--roi` 传入。坐标用 EXIF 校正后原图像素。逐一打开左原图、中许可、右实际帧三联图，记录具体天气、部位、偏差和图名。自动选取的类别点只代表该类别，部位不可见或没有独立参考时注明未测。
- 旧版按实际天气选择器轮巡，用时间窗检查粒子、晴天清空、隐藏恢复、减少动态和窗口尺寸。水纹按归一化落点投影核对，容差 2 CSS px。新版使用 motion.json 的种子、时刻和图层顺序，从实际页面调用 sample；未声明时间时在报告中记录所选秒数。遇到其他宿主接口，按交付清单补测，将运行截图与步骤纳入同一报告。

## 性能与版本对比

默认同一独立 Chromium 会话、960 × 540 CSS px、DPR 1，依次测晴朗、大雨、暴雪，每档预热 10 秒、采 60 秒、重复两轮。用 `--width`、`--height`、`--warmup`、`--seconds`、`--repeat` 调整；`--seconds 0` 仅跳过性能采样。目标帧率可用 `--target-fps` 记录。保持机器电源、窗口可见性与同时运行的负载可比。

```sh
.venv/bin/python skills/wallpaper-qa/scripts/qa.py "/作品/新版" --compare "/作品/旧版" --budget "/验收/预算.json" --out "/tmp/版本验收-01"
```

预算是以天气为键的指标上限，例如 `{"大雨":{"draw_p95_ms":55,"renderer_rss_mib":450},"暴雪":{"renderer_cpu_pct":80}}`。指标名称以 performance.json 中角色与报告为准。预算优先于版本基线。条件匹配时，P95 与旧版重复测量的上界比较；CPU/RSS 对比记录差值供评估。无预算与版本基线时，「性能实测通过」仅表示采样完成。区分绘制回调、RAF 与实际显示帧；按 PID/角色读取 CPU 与 RSS，统一内存总量、GPU 进程 RSS、GPU 分配量分别记录。

## 本地交付与结论

独立浏览器禁用网络、拒绝定位并打开 file URL。macOS 检查应用资源、签名与包内场景，在无定位输入的短时专用 WKWebView 中试切天气并退出。需要原生菜单、系统拒绝定位和桌面进程归属时，仅在确有独立测试入口或专用登录会话中操作；保留正在使用的壁纸。独立宿主的退出与用户安装应用的退出分别报告。

读 `qa-report.json` 和「验收报告.md」。每项应有通过／失败／未测、期望、实测、证据路径与最小复现步骤。报告目录保留原始间隔、进程样本、环境信息、图层坐标、裁图。人工观察追加到 checks 后同步更新人读报告。按新目录重跑即可保留上一轮证据。

[干净作品实测](examples/clean/验收报告.md) · [两种故障的临时副本实测](examples/faults/验收报告.md)。复验故障使用 `scripts/selftest.py`，参数为赛道作品、`--out`、可选 `--source` 和 `--roi`。它在临时副本修改图片及预览，核对报告里的区域、像素数和首个坐标，退出时删除副本。

发布验收还会启动实际 HTML、逐天气验证可见材质和粒子帧。路面正样本仅对实际被遮挡的像素豁免。
